# dickyadisaputra.com

Personal website for Dicky Adisaputra.

## Current structure
The homepage (`index.html`) is a "workspace" scene:
- Wall cards (looping carousel): Now, Journey, Ruang Ayat, Ruang Tumbuh, Writing, Belajar Menjadi Ayah, Moments, Let's talk. Each card opens as a printed-style book.
- Desk with a live calendar and Bogor clock.
- Bookcase that opens a "Favorite Books" shelf of books Dicky has read.
- Writing, Studio, and Ruang Tumbuh live at `/writing/`, `/studio/`, and `/ruang-tumbuh/`.

Homepage images are in `assets/room/`.

## Stack
Static HTML, CSS, and JavaScript for a lightweight first version that can be deployed easily to GitHub Pages, Cloudflare Pages, or Vercel.
